1. GitHubってなに？

インターネット上にある「ファイルの置き場所」と「変更の記録帳」がセットになったサービスです。

おもにプログラムのファイルを置くために使われますが、文章やメモなど、ふつうのファイルも置けます。

たとえば、こんなことができます。

  • 作ったファイルを、ネット上に保存しておく（バックアップ）
  • 「いつ・だれが・どこを変えたか」をあとから見られる
  • 前の状態に戻せる
  • ほかの人と、同じファイルをいっしょに作れる
💡 イメージとしては、「変更履歴が全部残る、みんなで使えるクラウドのフォルダ」です。

2. GitとGitHubのちがい

名前が似ていて、まぎらわしいところです。

Git（ギット）GitHub（ギットハブ）
なにか変更を記録する道具（ソフト）Gitで記録したものを置くネット上の場所（サービス）
どこで動く自分のパソコンの中インターネット上
たとえると日記帳日記帳をしまっておく、みんなで見られる本棚
👉 Gitで記録して、GitHubに置く、という関係です。

3. よく出てくる言葉

最初はこの5つを覚えておけば大丈夫です。

言葉かんたんに言うと例
リポジトリファイルを入れる「箱」（プロジェクトのフォルダ）「買い物アプリ」用のリポジトリ
コミット変更を「記録する」こと（セーブ）「見出しを追加した」と記録する
プッシュ自分のパソコンの記録を、GitHubに「送る」ことパソコン → GitHub
プルGitHubの最新の内容を、自分のパソコンに「持ってくる」ことGitHub → パソコン
ブランチ本体とは別に作る「おためし用の道」本体をこわさずに新しい機能を試す
💡 ゲームにたとえると、コミット＝セーブ、ブランチ＝別のセーブデータで寄り道です。

4. 基本の使い方

まずは、ブラウザ（Chromeなど）だけでできる流れを紹介します。

① アカウントを作る

  1. https://github.com を開く
  2. Sign up（登録）を押す
  3. メールアドレス・パスワード・ユーザー名を入れる

② リポジトリ（箱）を作る

  1. 右上の ＋ ボタン → New repository を選ぶ
  2. 名前を入れる（例：my-first-repo）
  3. Public（だれでも見られる）か Private（自分だけ）を選ぶ
  4. Create repository を押す

③ ファイルを入れる

  1. 作ったリポジトリを開く
  2. Add file → Upload files を選ぶ
  3. ファイルをドラッグして、下の Commit changes を押す
👉 これで、ファイルがGitHubに保存されました！

パソコンから使う場合（慣れてきたら）

ターミナル（黒い画面）では、こんなコマンドを使います。

git add .                     # 変更したファイルを記録の準備に入れる
git commit -m "見出しを追加"  # 変更を記録する（コミット）
git push                      # GitHubに送る（プッシュ）

5. GitHubでできる便利なこと

できることうれしいポイント
バックアップパソコンがこわれても、ファイルが残る
変更履歴を見る「いつ・どこを変えたか」がすぐわかる
前の状態に戻す失敗しても、やり直せる
みんなで作業同じファイルを複数人で直せる
作品を公開する自分の作ったものを、世界中の人に見てもらえる
ほかの人のコードを見る公開されているプログラムを読んで勉強できる

6. 上手に使うコツ

  1. こまめにコミットする
    • ✕ 1週間分の変更を、まとめて1回で記録
    • ○ ひとつ直すたびに記録
  2. コミットのメッセージをわかりやすく書く
    • ✕「修正」
    • ○「トップページの文字の色を青に変更」
  3. 見られたくないものは置かない
    • パスワードや個人情報は、リポジトリに入れない
    • 迷ったら Private にしておく
  4. 作業を始める前にプルする
    • ほかの人の変更を先に持ってきておくと、ぶつかりにくい

7. こまったときは

  • 😵 言葉の意味がわからない → 「3. よく出てくる言葉」を見返す
  • 🔙 前の状態に戻したい → ファイルの History（履歴）から、昔の内容を確認できる
  • ⚠️ パスワードなどを公開してしまった → すぐにそのパスワードを変更する（ファイルを消すだけでは、履歴に残っています）
  • 💥 プッシュでエラーが出た → 先に git pull で最新の内容を持ってきてから、もう一度プッシュする
  • ❓ どうしてもわからない → エラーの文章をそのままコピーして、Claudeに「これはどういう意味？」と聞く

まずはリポジトリを1つ作って、ファイルを置いてみましょう！ 🎉
